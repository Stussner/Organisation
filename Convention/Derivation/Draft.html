Derivation Rules — Draft

Status: Working draft; not yet a final convention.

Purpose

These rules define how a concrete software project derives its organization from the Organization Base.

Organization Base

  • Software projects reference the Organization Base as their higher-level organizational foundation.
  • The Organization Base is project-neutral. It does not know, list, or manage individual software projects.
  • The Organization Base is static for a software project. Codex chat and task administration must not alter it.

Derivation in a Software Project

  • Each software project contains a short, local reference file that identifies the Organization Base used by that project.
  • A project organization inherits the Organization Base where it has no local definition.
  • Project-specific organization may extend or redefine inherited organization within the project.
  • Local definitions apply only to the respective software project and do not modify the Organization Base.

Codex Workspace

  • The concrete software project remains the primary Codex workspace folder.
  • The Organization Base may be attached as a secondary workspace folder when Codex must read its conventions.
  • Any required read-only protection for the Organization Base must be enforced by the applicable access configuration.
