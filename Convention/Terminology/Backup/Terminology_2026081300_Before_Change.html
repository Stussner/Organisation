Terminology

Allgemeine Begriffe für die Verwaltung und Auswertung von Chats sowie für technische Ablagen.

Chat
Interaktion zwischen einem Menschen und einem KI-Agenten.
Chat Management
Verwaltung von Chats: benennen, Projekten zuordnen, ablegen, exportieren und wiederfinden.
Extraction
Gezieltes Herausziehen und Verdichten des Wesentlichen aus einem Chat, etwa von Ergebnissen, Entscheidungen, Aufgaben und Erkenntnissen. Präziser auch: Knowledge Extraction.
Datenoperationen
Allgemeiner Begriff für Tätigkeiten wie Laden, Speichern, Importieren, Exportieren, Erstellen und Löschen von Daten.
Repository
Eine verwaltete Ablage von Dateien. Bei Git umfasst sie ein Projekt einschließlich seiner gespeicherten Änderungshistorie.
Versionsverwaltung
Ein Verfahren oder System, das Änderungen an Dateien nachvollziehbar speichert und frühere Stände verfügbar hält.
Git
Ein System zur Versionsverwaltung von Dateien.
Hub
Ein zentralisierender Knotenpunkt, an dem Verbindungen, Informationen oder Funktionen zusammenlaufen.
GitHub
Eine Plattform, die Git-Repositories bereitstellt und Funktionen für Zusammenarbeit und gemeinsame Entwicklung bündelt.
Host
Ein bereitstellendes System. Es macht einen Dienst oder eine Ressource erreichbar, etwa ein Repository.
Proxy-Server
Ein Vermittlungsserver zwischen einem Gerät und einem anderen Server. Er leitet Anfragen weiter und gibt Antworten zurück, beispielsweise zur Zugriffskontrolle, Zwischenspeicherung oder Abschirmung interner Systeme.
