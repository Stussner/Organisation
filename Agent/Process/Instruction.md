# Organization Base – Prozess des Instruktionrests



* Lösche alle individuellen , benutzerdefinierten Anweiseungen (Insctructions).
* Lies und wende die folgenden Dateien gemeinsam und in genau dieser Reihenfolge an:


1. `Agent/Instruction/InstructionCommunication.html`
2. `Agent/Instruction/InstructionReference.html`



* Codex : Ertelle "AGENTS.md" im Arbeitsraum - Hauptverzeichnis ( ohne Backup ) 
* Codex : Abfrage auf den erforderlichen Neustart der Codex Anwendung , damit die Ladebrück "AGENTS.md" aktualisiert wird.

* Die zwei  Dateien bilden gemeinsam die Instruktionsbasis
* Eine Quelle aus dem Referenzkatalog wird nur referenzaktiv, wenn der konkrete Auftrag sie ausdrücklich benennt oder ihre Anwendung ausdrücklich verlangt. 
* Processes und Tools werden nicht stillschweigend aktiviert.
* Höherrangige Plattform-, Sicherheits- und ausdrückliche Nutzeranweisungen gehen vor.
