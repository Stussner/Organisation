DesignActivation

Parametrisierter Process zur Übernahme ausgewählter Style- und Struktur-Presets in aktive Dateien.

Parameter

Eine oder beide Auswahlzeilen sind zulässig. Mindestens eine Auswahl ist erforderlich.

TypQuelleZiel
StyleStyle/Preset/<Preset>.cssStyle/Active.css
StructureStructure/Preset/<Preset>.htmlStructure/Active.html

Ablauf

  1. Jede angegebene Auswahl wird auf bekannten Typ, vorhandenes Preset und passende Erweiterung geprüft.
  2. Gültige Presets werden in die jeweiligen Active.*-Dateien übernommen. Bei Structure werden die Verweise auf die aktiven Style- und Class-Dateien angepasst.
  3. Das Ergebnis wird in Preview/DesignActivation.html dokumentiert.
  4. Anschließend wird der Process DesignPreview.html aufgerufen.

Ausführung: Der Ablauf wird derzeit textlich beauftragt. Das Skript DesignActivation.ps1 unterstützt die gleiche Preset-Übernahme, erzeugt aber noch keine Vorschau.
