Chat Import

Dieser Process verwendet einen gespeicherten Chat aus dem Workspace als nachvollziehbare Kontextquelle in einem Codex-Projekt.

Quelle und Ergebnis

Die Quelle ist Original.html im zugehörigen Chat-Ordner. Der Import schafft einen neuen Chat oder ergänzt einen ausdrücklich bestimmten Chat um diese Quelle. Der neue Arbeitskontext benennt die Quelldatei und die ursprüngliche Chat-ID.

Auswahl der Chats

Import ohne Parameter verarbeitet alle verfügbaren Chatquellen. Import(this) verarbeitet ausschließlich die Quelle des aktuellen Chats. Import(<Chatname>, <Chatname>, …) verarbeitet ausschließlich die durch Komma getrennt angegebenen Chatquellen. this ist ein reservierter Parameter und kein Chatname. Jeder angegebene Chatname muss eindeutig zu einem Chat-Ordner mit Original.html passen; bei fehlender oder mehrdeutiger Zuordnung wird der betreffende Eintrag nicht verarbeitet und die Zuordnung wird berichtet.

Mehrfachimport

Bei mehreren Quellen wird für jede Quelle ein eigener neuer Chat angelegt, sofern nicht für diese Quelle ausdrücklich ein bestehender Zielchat bestimmt wurde. Quellen werden nicht zu einem gemeinsamen Chatverlauf vermischt.

Grenzen

Der Import stellt keine native Chat-Instanz wieder her. Chat-ID, Branches, Modellzustand, versteckte Inhalte und interne Sitzungsdaten werden nicht wiederhergestellt. Original.html, Extraction.html und Excerpt.html bleiben unverändert.
